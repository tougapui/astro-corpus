# 占星回測所｜盲測簿

星座運勢盲測工具：預測發布時自動加密封存（你看不到），你每天記錄生活，月底輸入密碼開箱、逐條對照，產出命中率與巴納姆指數。

## 系統架構

```
GitHub Actions（每週三 10:00 台北時間自動執行）
  ├─ 爬取瑪法達本週 12 篇分則（鏡週刊）
  ├─ 爬取唐綺陽新週報（Podcast RSS）
  ├─ 偵測唐綺陽新月運直播（YouTube RSS，僅登記待轉錄）
  └─ AES-GCM 加密封存 → commit 到 repo
GitHub Pages（docs/）
  └─ 盲測簿前端：每日記錄（localStorage）＋封存庫＋月底開箱對照
```

封存內容以你設定的密碼加密。不輸入密碼誰都看不到內容——包括你自己，這就是盲測；同時原文不會以明碼暴露在公開 repo。

## 上線步驟（一次性，約10分鐘）

1. **建立 repo**：GitHub 新增 public repository（例：`astro-blindtest`），把本資料夾所有檔案推上去（含 `.github/` 隱藏資料夾）。
2. **設定封存密碼**：repo → Settings → Secrets and variables → Actions → New repository secret，名稱 `SEAL_KEY`，值填一個你記得住的密碼（開箱時要輸入同一個）。
3. **開啟 Pages**：Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/docs`，存檔。幾分鐘後你的盲測簿網址就是 `https://<帳號>.github.io/astro-blindtest/`。
4. **首次執行封存**：repo → Actions → weekly-archive → Run workflow。跑完後 `docs/data/sealed/` 會出現本週的加密封存與 `index.json`。
5. **手機加入主畫面**：用手機瀏覽器打開網址 → 分享 → 加入主畫面，之後每天點開記錄一分鐘。

之後每週三早上系統自動封存，不需要人工介入。

## 日常使用

- **每天**：打開盲測簿 → 今日記錄 → 五項評分＋一句話 → 記錄。不要去想任何預測。
- **每週三後**：封存庫會多一批「封」印，你只看得到數量。
- **月底過後**：開箱對照 → 選月份 → 輸入密碼 → 逐條判定命中／未命中／無法驗證 → 看統計。「無法驗證」的比例＝巴納姆指數。
- **月運直播**：封存庫的「待轉錄」出現新影片時，照 PROJECT.md 的 NotebookLM 流程手動取得逐字稿（此部分無法自動化：該頻道未開放字幕）。

## 注意事項

- 每日記錄存在瀏覽器 localStorage，**換裝置前務必用「匯出」備份**（開箱判定結果也在裡面）。
- 密碼忘了＝封存內容永遠打不開，沒有找回機制。
- 爬蟲禮貌：腳本只在每週三抓一次當週內容，勿改成高頻排程。
- 研究倫理：封存原文僅供個人盲測研究，公開分享結果時用統計數字與改寫，不重製原文。
